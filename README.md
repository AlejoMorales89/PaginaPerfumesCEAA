# Esencia Viva — Página web de perfumes

Sitio web estático e interactivo para presentar cuatro perfumes artesanales:

- Hierbabuena con base de alcohol
- Coco con base de alcohol
- Coco con base de aceite
- Naranja con base de alcohol

Incluye las fotografías del proyecto en `Imagenes_pagina/` y contenido educativo sobre maceración, moléculas aromáticas, fórmulas químicas, olfato y grupos funcionales.

## Ver el sitio

Abre `index.html` en un navegador. No requiere instalar dependencias ni ejecutar un servidor.

## Publicarlo sin instalar Git

1. En GitHub, crea un repositorio público llamado `PaginaWebPerfumes`.
2. Dentro del repositorio, selecciona **Add file → Upload files**.
3. Desde el Explorador de archivos, arrastra a la página los archivos `index.html`, `styles.css`, `script.js`, `README.md` **y la carpeta completa** `Imagenes_pagina`. También puedes seleccionarlos con el botón de carga; conserva la carpeta de imágenes para que no se rompan las fotos.
4. Escribe un mensaje de confirmación y pulsa **Commit changes**.
5. Abre **Settings → Pages**. En **Build and deployment**, elige **Deploy from a branch**, selecciona `main` y la carpeta `/(root)`, y guarda.
6. Cuando termine la publicación, GitHub Pages mostrará el enlace público en esa misma sección. Puede tardar unos minutos en estar disponible.

## Alternativa: GitHub Desktop

1. Instala y abre **GitHub Desktop** e inicia sesión en tu cuenta de GitHub.
2. Selecciona **File → Add Local Repository** y elige esta carpeta: `Pagina_Web_Fragancias`.
3. Si GitHub Desktop indica que todavía no existe un repositorio Git, selecciona **create a repository** y usa el nombre `PaginaWebPerfumes`.
4. Confirma los archivos, escribe un mensaje de resumen y selecciona **Commit to main**.
5. Selecciona **Publish repository**, verifica que el nombre sea `PaginaWebPerfumes` y desmarca la opción para mantenerlo privado.
6. Activa GitHub Pages siguiendo los pasos 5–6 de la sección anterior.

Conserva la carpeta `Imagenes_pagina` junto a `index.html`: el sitio utiliza esas rutas locales para mostrar las fotografías.
