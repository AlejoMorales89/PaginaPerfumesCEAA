# Esencia Viva — Página web de perfumes

Sitio web estático e interactivo para presentar cuatro perfumes artesanales:

- Hierbabuena con base de alcohol
- Coco con base de alcohol
- Coco con base de aceite
- Naranja con base de alcohol

Incluye las fotografías del proyecto en `Imagenes_pagina/` y contenido educativo sobre maceración, moléculas aromáticas, fórmulas químicas, olfato y grupos funcionales.

## Repositorio y sitio publicado

Repositorio: [AlejoMorales89/PaginaPerfumesCEAA](https://github.com/AlejoMorales89/PaginaPerfumesCEAA).

Una vez activado GitHub Pages, el sitio estará disponible en:

<https://alejomorales89.github.io/PaginaPerfumesCEAA/>

## Activar GitHub Pages

1. Abre la pestaña **Settings** del repositorio y selecciona **Pages**.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/(root)`; pulsa **Save**.
4. Espera a que termine la publicación. GitHub mostrará el enlace en esa sección; la primera publicación puede tardar unos minutos.

Conserva la carpeta `Imagenes_pagina` junto a `index.html`: el sitio utiliza esas rutas locales para mostrar las fotografías.

## Ver el sitio sin publicarlo

Abre `index.html` en un navegador. No requiere instalar dependencias ni ejecutar un servidor.
